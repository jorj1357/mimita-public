# MiMITA Documentation

Use `C:\mimita-priv-v8\AGENTS.md` as the starting router.

## Folders

- `specs/` — intended behavior
- `architecture/` — ownership and implementation boundaries
- `operations/` — build, deployment, assets, and completion procedures
- `regressions/` — documented failures and prevention checks
- `investigations/` — active technical investigations
- `releases/` — release-specific records
- `specs/old-specs/` — historical specifications, not current defaults

The first migration keeps the original specification files as backups while the
organized copies are verified.
