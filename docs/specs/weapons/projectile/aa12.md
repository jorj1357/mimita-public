# AA-12

**Purpose:** define an automatic-style AA-12 shotgun with semiautomatic firing
for Bloodtest.
**Audience:** weapon, projectile, networking, audio, animation, and gamemode
contributors.
**Does not:** imply a real-world rate of fire or finalized balance values.

## Behavior

- The AA-12 launches shotgun pellet projectiles using the shared shotgun and
  projectile owners. Each pellet has a finite physical trajectory, gravity
  drop, and independent collision; no hitscan spread cone or instant beam is
  allowed.
- It is semiautomatic: one press produces one shot. The minimum delay between
  shots is short and configurable; holding the trigger must not convert it to
  automatic fire.
- It has a loud, powerful firing report distinct from the existing shotgun.
  Magazine/reserve, pellet count/spread, damage, ballistics, recoil, reload,
  sound, and equip/unequip timing are per-weapon JSON values.
- World contact uses bullet-hole/debris effects. Actor hits use Bloodtest's
  blood/body response; neither path uses explosive launcher visuals.

## Acceptance

Verify one shot per press, short configured repeat delay, distinct loud report,
physical pellet trajectories/drop, authoritative contacts, and stable
concurrent-fire performance.
