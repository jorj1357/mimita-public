# Gold note: Map Editor made Payload authoring easier

- User feedback reported: 2026-10-26 (local date; exact time not supplied)
- Context: the player tried the Map Editor while working on Payload.
- Audience: gameplay, map-editor, and animation-authoring designers
- Purpose: preserve a positive human usability signal and connect it to a follow-up authoring idea.
- This note does not establish a specific build, measured editing-time reduction, acceptance of every editor workflow, or a technical cause.

## Player feedback

The player said that using the Map Editor was “super good,” that they liked it, and that it made working on Payload much easier.

This is direct positive user feedback about Payload map authoring. The player did not provide the build, exact editor operations, or a session record in this message, so it should not be generalized to every editor task or treated as a measured usability result.

## Design lesson

The player wants animation authoring to reach a similar level of approachability while remaining hand-authored. They suggested exploring ways to create motion without directly placing keyframes for every pose. This motivates an animation-authoring investigation; it does not select a replacement for the current Blender Action/keyframe workflow or change the shared animation format/runtime.
