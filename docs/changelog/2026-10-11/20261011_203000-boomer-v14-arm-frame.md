# Boomer v14 arm frame correction

Date: 2026-10-11 (EST)
Status: ASSET_COMPLETE_WITH_RUNTIME_VISUAL_REVIEW_PENDING

## Request

Create a Boomer v14 GLB whose arms use the same shoulder-pivot and local frame
as `mimita-char-no-animations-v4.glb`, so camera aiming and shotgun poses work
like Jason's.

## Change

- Created `assets/entity/player/monsters/boomer/mimita-boomer-v14.glb` from
  v13.
- For `leftArm` and `rightArm`, transformed every POSITION from
  `(x,y,z)` to `(x,-z-max_z,y)`. This is a +90-degree X frame conversion plus
  a translation that puts the upper endpoint at the node origin.
- Applied the matching `(x,y,z)` to `(x,-z,y)` rotation to both arm NORMAL
  accessors.
- Kept all node transforms and the shared runtime animation/aim code unchanged.
- Updated `assets/avatars/monstertest1/avatar.json` to select v14.

## Static validation

- Both arm nodes remain named `leftArm` and `rightArm`.
- Their node transforms are unchanged from v13.
- Their mesh bounds are now approximately local `Y=-2.470..0.000` with the
  long axis matching the default model's local Y arm frame.
- The v14 GLB remains a valid glTF 2.0 binary with seven nodes, six meshes,
  no skin, and no authored animation clips, like the source rigid-part model.
- `body_transform_source` remains `model`.
- No source build was required for this asset-only change.

## Runtime boundary

The real game still needs to load `monstertest1` and visually confirm that both
arms pivot from the shoulders, follow camera pitch/yaw, and hold the shotgun at
the same hand/barrel relationship as Jason. Build/static asset evidence is not
being treated as visual acceptance.
