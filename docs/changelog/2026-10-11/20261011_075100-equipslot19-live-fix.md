# `equipslot19` Heavy Shotgun logical-slot fix

Date: 2026-10-11 (America/New_York)

## Outcome

`equipslot19` now follows the normal community logical-slot path. In sandbox,
the active all-weapons set resolves logical slot 19 to `heavy_shotgun`, whose
native definition slot is 24. The existing 1–9 hotbar mapping is unchanged.

Equip startup commands now wait for the authoritative weapon-set ID before
dispatching, preventing an early client command from using an uninitialized
slot map.

## Evidence

- User-provided run `20261011_073541` showed the original failure: the client
  reported that slot 19 was unavailable while the run used the older explicit
  weapon set 1.
- Fresh dev-loop run `20261011_074924` used build 2018 with sandbox
  `--weapon-set 5` and matching client/server binaries.
- `startup.command.dispatch` recorded `equipslot19` after connection and world
  readiness.

  `requested_logical_slot: 19`, `mapped_weapon_id: heavy_shotgun`,
  `resolved_native_slot: 24`, and `weapon_set_id: 5`.
- Server `weapon.equip.accepted` recorded logical slot 19 resolving to native
