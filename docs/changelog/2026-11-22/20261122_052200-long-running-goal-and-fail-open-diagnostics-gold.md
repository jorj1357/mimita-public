## Changes

- Added a recommended-practice section to [the agent-session gold reference](../../gold/20261030_033224-agent-session-handoff-gold.md). It says to preserve objective, later steering, constraints, verified results, and open work across activations; keep progressing while waiting; checkpoint concrete evidence; and leave the goal active until acceptance is met. It explicitly coexists with the existing guidance to use a fresh session plus a factual handoff when context gets noisy.
- Added a fail-open section for optional profilers and samplers. Their status must be separate from build status; if a profiler is unavailable, preserve the exact error and continue with a safe evidence fallback. Compiler, linker, codegen, source-coherence, and cache-freshness failures remain fail-closed.
- Appended the observed WPR failure and the goal-continuity proposal to the relevant issue discussions.
