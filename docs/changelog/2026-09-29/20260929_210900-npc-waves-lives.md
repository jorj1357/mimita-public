# NPC Waves player lives and game over

Time: 2026-09-29 21:09:00 EDT

## Implemented

- Added `lives` to `config/gamemodes/npc_waves.json`, defaulting to 3. Set it
  to `999` for development testing.
- Added authoritative wave life accounting. A lethal player event consumes one
  life exactly once; a player respawns immediately only while lives remain.
- Removed the repeated-death respawn path after the life budget reaches zero.
  The player becomes terminally spectating and the wave run enters results.
- Replicated remaining lives and highest wave in `DuelStatePacket` (protocol
  version 38).
- Added JSON-defined `livesText` and `gameOverText` presentation to the active
  NPC Waves GUI layout.
- Preserved NPC terminal-death behavior and the previously implemented spawn
  during the `WAVE N` banner.

## Human validation still required

Start `npc_waves`, die once, verify the player respawns once and the HUD shows
2 lives, then repeat until the HUD shows `GAME OVER - HIGHEST WAVE: N`. Set
`lives` to `999`, restart the mode, and verify the larger budget is applied.
