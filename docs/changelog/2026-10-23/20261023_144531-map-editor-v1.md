## Change

### Editor state and input

- Added `src/mapeditor/map-editor.h`, `map-editor.cpp`, and
  `map-editor-commands.cpp`.
- Added `mapeditor 1|0|status|save|reload|freeze|add|selectall|copy|paste|cut|duplicate|delete|undo|redo|help`
  and `mapeditor_freeze`.
- Reuses the existing gameplay freecam for WASD/Q/E movement and
  `Camera::updateMouse` for RMB look.
- Editor mode owns cursor policy: free cursor by default, capture only while RMB
  is held, and restore the previous mouse-lock state on exit.
- Gameplay combat input is gated off while the editor is active.
- The editor can freeze or unfreeze world simulation independently of the
  detached camera.
- Selection uses stable entity/block/route/cart IDs. LMB selects/drags,
  Shift+LMB multi-selects, axis handles constrain movement, V toggles vertex
  snap, G toggles grid snap, and F frames the selection.
- Copy/paste/cut/duplicate/delete and undo/redo are in-memory editor operations.
  Ctrl+S remains the explicit persistence action.

### Map data and persistence

- Extended `MapConfigRegistry` with authored blocks, payload route points/cart
  origin, authored-data revision, snapshots, and restore.
- Save now validates generated JSON, writes through a temporary file, creates a
  timestamped backup under `config/maps/backups/<mapId>/`, and retains the
  newest 50 backups.
- Added `config/maps/backups/` and `config/maps/editor-autosaves/` to
  `.gitignore`.
- Added deterministic block/route save/load coverage to
  `mapEntityConfigSelfTest`.

### World and server geometry

- Added `src/map/map-authored-geometry.{h,cpp}`.
- Authored box blocks are generated as render vertices and collision triangles,
  appended after the GLB base, and rebuilt on editor changes.
- Applied authored blocks during client map load and to dedicated/listen-server
  headless worlds.
- Server NPC collision derives from the headless world, so authored blocks reach
  NPC navigation through the existing path.
- Added `map-authored-geometry.applied` structured events with block, vertex,
  triangle, and revision counts.

### Editor rendering and commands

- Editor world overlay draws entity/block/route markers, route polyline,
  selection, move handles, and snap target.
- Editor HUD shows map, dirty state, freeze state, selection/counts, status, and
  controls.
- Added `map-block.created`, `map-payload-route-point.created`, and
  `map-entity.saved` structured events.

## Known scope limits

- Arbitrary baked GLB triangles are still not individually editable.
- Remote multiplayer editing is not implemented; editor saves are local.
- Block rotation/scale handles are not part of this slice; move handles and
  snapping are.
- Blender live sync and GLB export were intentionally skipped.
- Delete/cut key paths compile and share the tested mutation path, but their
  live delivery was interrupted by the client disconnect and still needs a
  human interaction pass.
