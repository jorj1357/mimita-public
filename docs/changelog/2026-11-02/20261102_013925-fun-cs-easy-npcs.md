## Goal

Make NPC opponents using Fun Counterstrike's `fun_cs_rush` profile much easier
to beat while preserving objective rush, bomb interactions, and shared movement.

## Changes

- `config/behavior-profiles.json`: changed `fun_cs_rush` to beginner, 25-degree
  aim error, a 120-tick minimum accepted-shot interval, and 0.1 dash chance.
- `src/npc/npc.cpp`: objective-rush combat dashes now use the configured chance
  instead of always dashing.
- `src/npc/npc-traversal.cpp` and `.h`: optional open-route dashes now use the
  profile chance. Dashes required to cross gaps or large steps remain available.
- Updated `docs/specs/gamemodes/funcounterstrike.md` and
  `docs/specs/npc-behavior/npc-behavior.md` to describe these settings and remove
  the requirement to dash whenever ready.
- Added OGI-020 to `docs/specs/open-gameplay-issues.md` for live difficulty
  acceptance.

The worktree was already dirty before these changes. Other pre-existing edits
were retained; in particular, `src/npc/npc.cpp` had existing unrelated edits.

## Runtime evidence

Ran `devscripts/scenarios/fun_cs_npc_objective_v1.json` through the dev loop
against build 212. It passed all seven assertions, including NPC rush, bomb
planting, and defuser assignment. Journal:
`logs/2026-11-02/20261102_013203/events.jsonl`.

The journal recorded beginner decisions, a maximum shot aim error of 25 degrees,
and a minimum observed accepted-shot gap of 480 ticks for the same NPC. The
observed interval exceeds the configured 120-tick floor, as weapon cadence can
lengthen it. Two NPCs emitted the one-time `npc.dash` event across 16,698 server
ticks. This supports the reduced-dash behavior, but the event is logged once per
actor and does not measure a full dash probability distribution. A prior build
211 run, before optional route dashes were gated, logged around 20 distinct
dashing NPCs in a shorter run.
