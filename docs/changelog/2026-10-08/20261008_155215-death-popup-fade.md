# Death popup fixed-tick fade

Date: 2026-10-08 15:52:15 -04:00 (EST)
Branch: `afad20a-rebuild`

## Result

The local death popup now starts fully opaque, fades linearly to transparent
over exactly 600 client UI ticks, and is no longer drawn after tick 600. The
clock is the existing fixed 60 Hz `UiTickClock`, so the lifetime is independent
of render-frame rate. Becoming alive again resets the popup lifetime for the
next death.

- `src/engine/engine-tick-ui-game-hud.cpp:104-112`: the generic HUD panel pass
  was drawing `deathOverlay` every frame, even when the death branch was not
  active. The panel is now excluded from that always-on pass.
- `src/engine/engine-tick-ui-game-hud.cpp:115-123`: HUD text accepts an alpha
  multiplier, preserving all existing callers at alpha 1.0.
- `src/engine/engine-tick-ui-game-hud.cpp:223-272`: added a per-death popup
  start tick, a 600-tick lifetime, linear alpha calculation
  `1.0 - elapsed / 600.0`, and matching alpha/deletion behavior for the panel,
  death text, respawn text, and respawn hint.
