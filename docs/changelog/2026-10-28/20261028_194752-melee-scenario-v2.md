## Scope

Implemented schema 2 scenario capture/replay for melee diagnosis:

- version 1 recordings remain loadable;
- client actor tracks record rendered transforms, health, generations,
  equipment/action state, collision poses, and weapon contact capsules;
- the local dev-loop server records a matching authoritative actor track;
- the client merges the server sidecar into one scenario file;
- playback creates Npc-backed target proxies, drives them from the recorded
  authoritative track, disables AI for those proxies, and never proxies live
  connected humans;
- playback now requires client/server spawn readiness, restored start state,
  matching map/weapon set and move-set revision/hash, and fails on readiness
  timeout or the first position error above 2 m instead of snapping;
- spawn acknowledgement/activation and scenario contact/weapon contacts emit
  bounded diagnostics with generation and transform epoch.
