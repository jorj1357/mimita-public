## Change

Added a hot-reloadable `limbBounceMode` switch to `config/collision.json`:

- `2` (default, current behavior): animated limbs only add a damped root push
  (`25%` of the configured part-driven response); weapon contacts keep full
  rebound.
- `1` (legacy behavior): animated limbs and weapons both use the full configured
  part-driven bounce, so limbs can launch the player again.

Changed:

- `src/config/collision-config.h`
  - added `int limbBounceMode() const`;
  - added `int mLimbBounceMode = 2;`.
- `src/config/collision-config.cpp`
  - parses `limbBounceMode` and clamps it to `1..2`;
  - includes it in the existing collision-config reload log.
- `src/physics/movement/physics-collision-shared.h`
  - part-driven root push now uses:
    ```cpp
    const bool legacyLimbBounce =
        CollisionConfig::instance().limbBounceMode() == 1;
    const float partWeight = (weaponPart || legacyLimbBounce) ? 1.0f : 0.25f;
    ```
- `config/collision.json`
  - added `"limbBounceMode": 2` with a comment documenting modes `1` and `2`;
  - existing `maxSpeed: 50` and `strength: 0.35` values were preserved.

The existing `CollisionConfig::pollHotReload()` path reloads the new value, and
the response reads the getter per contact, so switching the JSON between `1`
and `2` takes effect without restarting.
