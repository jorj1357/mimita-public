1. `revolver`
2. `shotgun`
3. `swordsword`

Changed `config/gamemodes/tdm.json:13` from `weapon_set_id: 1` to `weapon_set_id: 29`.

Removed the `weapon_set` overrides from TDM's two role definitions, `elite_fighter` and `elite_npc`, in `config/roles.json:31-46`. Repository search found these role IDs are referenced by TDM only. Both roles now inherit the active mode weapon set, so players and NPCs share TDM's default set rather than players receiving `standard` and NPCs receiving `elite_arsenal`. The existing starting weapon remains revolver.

The shared gamemode specification says an explicit GUI/runtime weapon-set selection takes precedence over `weapon_set_id`. That policy is unchanged; when a host explicitly selects another set, the roles inherit that active set as well.
