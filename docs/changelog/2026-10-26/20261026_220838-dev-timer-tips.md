## Request and source

The user chose a gentle, optional reminder: `devtimertips 1|0`, saved between launches, off by default in all builds. While enabled, each second posts a separate one-second notification containing current session seconds and a random personal message. Both title and message use white RGB. The timer resets on each launch and counts menu time.

The GUI specification requires: “IF IT IS A GUI ELEMENT, ITS PRESENTATION MUST BE JSON-DEFINED AND JSON HOT RELOADABLE.” Existing gameplay tips were enabled and shared `config/tips.json`; adding personal reminders there would expose them to ordinary players. Existing `tips` command persisted the general tip preference but did not track a session timer. `src/notifications/notifications.cpp::updateTips` only runs in gameplay.
