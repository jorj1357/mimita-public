# Add dev launch mode picker

- Date: 2026-09-28 (UTC)
- Scope: interactive `dev-loop.py` mode selection
- Result: PASS_WITH_HUMAN_REVIEW

## Behavior

While `dev-loop.py` is running:

1. Press `2` to display every mode from `devscripts/dev-launch-modes.json`.
2. Press the mode number, such as `1` or `2`, to select it.
3. Press `1` to build/retry or launch using the selected mode.

The status block now shows the selected launch mode. The choice lasts for the
current dev-loop session and is written to `.dev/state.json`; changing the JSON
table or restarting the loop can provide a different selection.

## Implementation

`devscripts/dev-loop.py` now owns a small picker state. `key_commands()` handles
mode selection before the existing build key, `show_launch_modes()` reads and
lists the JSON entries, `state()` records the selected mode, and
`_status_lines()` displays it. Invalid mode numbers are ignored without
changing the current selection. The previously added launch-mode argument
table remains data-owned by `devscripts/dev-launch-modes.json`.
