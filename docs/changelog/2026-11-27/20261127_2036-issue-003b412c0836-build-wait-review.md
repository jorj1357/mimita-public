in 427.963s and the 60s crossing fired inside the single changed TU
(`recast-navigation.cpp`, 285.963s), so a flat 60s budget is below that TU's
natural compile time. Duration inflation (~2.32x vs the prior gen-804 build of
the same TU) coincides with a concurrent NPC-heavy live run; that is
correlation, not proven causation. The spec already requires this TU to be
split (hard ceiling 30s; documented outlier 95-123s), so this is both alarm
noise and a spec-mandated latency defect.
