The AI’s workflow would be:
1. Ask the dev loop for status.
2. See whether a server/client is already running.
3. Stop the old server if it belongs to the previous build.
4. Build the current source.
5. Launch the selected mode from dev-launch-modes.json.
6. Wait for run.server-ready.
7. Wait for run.client-ready.
8. Read the exact journal path from current-run.json.
9. Follow events.jsonl while the game runs.
10. Detect useful events, crashes, spikes, missing events, and timing gaps.
11. Stop the run or let it continue.
12. Produce an evidence-based conclusion.
The AI should be able to say:
This run used build 1700.

C:\mimita-v9\.dev\builds\1700\mimita.exe
